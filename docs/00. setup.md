# Setup local

## Requisito real para esta version del proyecto

Para levantar y validar el stack local solo necesitas:

- Docker Desktop
- Docker Compose
- PowerShell

Herramientas como `kubectl`, `minikube`, `helm`, `k6` local o Python local son opcionales para esta etapa.

## Comandos base

```powershell
docker --version
docker compose version
docker info
```

## Arranque

```powershell
docker compose down -v
docker compose up --build -d
docker compose ps
```

## Si BuildKit falla

```powershell
docker compose build --no-cache
docker compose up -d
```
